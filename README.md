# Website-Demo

## Projektbeschreibung
Dieses Projekt ist eine Demo-Website, die verschiedene Webtechnologien und -techniken demonstriert.

## Installation
1. Klone das Repository:
    ```bash
    git clone https://github.com/dein-EnesYildiz24/Website-Demo.git
    ```
2. Navigiere in das Projektverzeichnis:
    ```bash
    cd Website-Demo
    ```
3. Installiere die Abhängigkeiten:
    ```bash
    npm install
    ```
